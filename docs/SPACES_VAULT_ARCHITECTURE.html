3. The Secret: Smart Range-Read Strategy

⚡ 99.8% Bandwidth Reduction
Audio metadata (ID3v2 tags, Vorbis comments, FLAC headers) lives at the very beginning of the file (first 64KB–192KB). Instead of downloading entire multi-megabyte files, the scanner issues a single HTTP Range request: Range: bytes=0-196607. 
async function fetchHeaderChunk(bucket, key) {
  const command = new GetObjectCommand({
    Bucket: bucket,
    Key: key,
    Range: "bytes=0-196607", // Only fetch the first 192KB!
  });
  const response = await s3Client.send(command);
  return streamToBuffer(response.Body);
}
